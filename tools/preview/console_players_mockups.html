Questions, each with a default

  1. Which layout? Default: A.
  2. Command name. Default: keep players (and online); only the console's output changes. Alternative: a new console-only command such as whereis, leaving players as it is.
  3. In-game staff. Default: staff keep today's one-line-per-server list, since chat is narrow and has no fixed-width font.
  4. A name filter. Default: yes, players Ste shows only names starting with "Ste".

Every line is in messages.toml, so the wording and colours can change later without a new jar.
