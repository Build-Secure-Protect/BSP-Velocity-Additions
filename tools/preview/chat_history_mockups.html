Chat history on join BSP-Velocity Additions, T25

When a player joins the network, the proxy sends them the recent public chat from every server: the last 50 lines, none older than 30 minutes. Each card shows Alex logging in on BSP-Spawn after a quiet quarter hour. History lines show exactly as live relayed chat did (same prefixes, RankUp images as coloured bars here); no line names a server for normal players (D18), and staff see the server tag on history lines as on live ones. Team chat and blocked chat are never kept. Decided 2026-11-18: look A (D37), built.

History looks like chat, framed by two grey lines. Easy to tell where old ends and new begins; the lines keep their colours and images, so rank prefixes read as usual.

[chatHistory]
header = "<gray>─── Earlier chat ───"
# each line: chat.relay (staff: chat.relayStaff)
footer = "<gray>─── Now ───"

Old lines in dark grey, as plain text. Impossible to mistake for live chat, but colours and RankUp's images are lost (an image would be tinted grey), so the line is rebuilt from the name and text.

[chatHistory]
header = "<dark_gray>Earlier chat:"
line   = "<dark_gray><<player>> <text>"
footer = ""

Each old line says how long ago it was said (minutes, rounded). Most informative; the extra column makes long lines wrap sooner. One marker line after.

[chatHistory]
header = ""
line   = "<dark_gray><ago></dark_gray> <line>"
footer = "<gray>─── Now ───"
