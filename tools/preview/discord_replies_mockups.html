Herald Bot Replies VA-D1 · mock-up set 1

The Discord bot's answers that the picked look A (BSP-Core discord_herald_concepts.html) did not draw yet: a code that does not work, the test DM, /unlink, /linkstatus, and the answer when the bot cannot reach the game network. The warning, outcome and channel cards and the green Linked card stay exactly as picked. Every answer to a command is seen only by the player who typed it. No answer ever shows a Discord name or number.

Decided 2026-10-25 (D24): option A, cards throughout. /unlink always needs a name (D25), so nobody unlinks every account by accident; the drawings below show /unlink name: Mrgregles_Alt. The same example everywhere: the Discord user who types the commands has linked two Minecraft accounts, Mrgregles and Mrgregles_Alt (D22).
