RankUp names in the tab list BSP-Velocity Additions, T23 (RankUp request RU-R3)

BSP-RankUp draws each player's rank prefix (as its image when the rank has one) and achievement suffix in the tab list. Today the proxy rewrites every name every 3 seconds with a plain-text prefix, so the images and suffixes vanish. Each card shows what Steve, on BSP-Spawn, sees with six players on four servers. Coloured bars stand in for RankUp's images. No option shows which server anyone is on (D16). Decided 2026-11-07: option A (D35), built.

Questions, each with a default

  • Which option? Default: A, as RankUp asked.
  • /players. Default: unchanged, text prefixes (chat lines from the proxy cannot borrow a tab row's name safely, and the console must stay readable).
  • Order. Default: unchanged; the client sorts the rows.
