Network join and leave lines BSP-Velocity Additions, feature 4

Three ways the proxy can announce a player who really joins or leaves the network. Every option is a MiniMessage line in messages.toml, so the wording and colours stay editable afterwards. Decided 2026-10-18: option A. The faded third line (a "moved to another server" message) was dropped altogether: a move line would let players track each other across servers (decision D15).

A · Vanilla

default
<Alex> anyone at spawn?
Steve joined the game
<Steve> back, got kicked by the storm
Mrgregles left the game
Steve moved to BSP-Wild

Looks exactly like single-server Minecraft. Players see no change, only fewer lines, because switching servers no longer prints anything. Nothing says which server anyone is on.

join  = "<yellow><player> joined the game"
leave = "<yellow><player> left the game"
moved = "<gray><player> moved to <to>"   # shown only with announceMoves = true

B · Signs

compact
<Alex> anyone at spawn?
[+] Steve
<Steve> back, got kicked by the storm
[-] Mrgregles
[>] Steve → BSP-Wild

Short and scannable. The colour of the sign carries the meaning, so a busy chat stays readable. The network style many large servers use; no server names.

join  = "<gray>[<green>+<gray>] <white><player>"
leave = "<gray>[<red>-<gray>] <white><player>"
moved = "<gray>[<aqua>><gray>] <player> → <to>"

C · Where

informative
<Alex> anyone at spawn?
Steve joined the game on BSP-Wild
<Steve> back, got kicked by the storm
Mrgregles left the game from BSP-Spawn
Steve went to BSP-Wild

Vanilla wording plus the server. Friends can tell where to find someone without a command. The grey tail keeps the line calm; it is the first thing to cut if the names get long.

join  = "<yellow><player> joined the game <gray>on <server>"
leave = "<yellow><player> left the game <gray>from <server>"
moved = "<gray><player> went to <to>"

Same in every option.

  • A join line is sent once, when the player has landed on their first backend. A leave line is sent once, when they disconnect from the proxy. Switching servers with BSP-Teleport never prints anything (D15).
  • Everyone on the network sees the line, the joining player included, as in vanilla.
  • Players with the permission bspva.joinleave.silent (staff who slip in quietly) produce no lines.
  • Placeholders: <player>, <server> (the server joined or left from).
  • Until BSP-Teleport builds request VA-T1, each backend still prints its own vanilla "joined the game" and "left the game" on every switch, so during testing both kinds of line appear.
