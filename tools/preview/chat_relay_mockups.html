Cross-server chat lines BSP-Velocity Additions, feature 2

How a chat line from another server looks when it arrives. BSP-Core sends the proxy the line exactly as that server showed it (prefixes, team tags, colours included), and the proxy forwards it to everyone elsewhere. The only open question is the tag in front. Each card shows the same moment: Alex on BSP-Spawn, Steve speaking from BSP-Wild, and what a staff member with bspva.players.servers sees.

Decision D6 (taken as a default on the first day) put [BSP-Wild] in front of every relayed line. Decisions D15 and D16, taken later, hide servers from players so nobody can track anyone. A server tag on chat would undo that: every message would say where its speaker is. Options A and B keep D15; C is D6 as written. Decided 2026-10-18: option A (D18).

A · One chat

chosen · default
Alex, on BSP-Spawn
<Alex> anyone selling plasma?
<Steve> [Warden] yes, 40 each
<Nadia> same here
staff, on BSP-SafeRoom
[BSP-Spawn] <Alex> anyone selling plasma?
[BSP-Wild] <Steve> [Warden] yes, 40 each

Remote lines look exactly like local ones. The network reads as one server; nothing tells a player where anyone is. Staff still see the tag, as with /players.

[chat]
relay      = "<line>"
relayStaff = "<gray>[<server>]</gray> <line>"

C · Server tag

D6 as written
Alex, on BSP-Spawn
<Alex> anyone selling plasma?
[BSP-Wild] <Steve> [Warden] yes, 40 each
[BSP-SafeRoom] <Nadia> same here
staff, on BSP-SafeRoom
[BSP-Spawn] <Alex> anyone selling plasma?
[BSP-Wild] <Steve> [Warden] yes, 40 each

Everyone sees where every line came from. The clearest, and the one that lets players track each other by reading chat, which D15 ruled out for join and leave lines.

[chat]
relay      = "<gray>[<server>]</gray> <line>"
relayStaff = "<gray>[<server>]</gray> <line>"

Same in every option.

  • The line itself is the backend's own: the same prefixes, team tags and colours the speaker's server showed. With chat.useBackendFormatting = false it becomes a plain <Name> text.
  • Players on the speaker's own server see nothing extra; they already saw the line. Players not yet on a backend see nothing.
  • Team chat, chat blocked by Region Guard and commands never cross: BSP-Core never sends them (its request VA-C2).
  • Only bytes from a backend count. A client sending on the channel is dropped.
  • Every relayed line also goes to the proxy console with its server, so the whole network's chat is in one log.
  • Needs proxy.relayChat = true in BSP-Core's server config on every backend.
